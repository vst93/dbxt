# dbxt

[English](README.md) | **中文**

基于 [DBX](https://github.com/t8y2/dbx) 内核的终端数据库 TUI，键盘优先。连接只需配置一次 —— 在 DBX 桌面端、DBX CLI 或 dbxt 本身 —— 之后任何终端都能用。单个静态二进制：无桌面端、无守护进程、无 HTTP 服务。

## 30 秒上手

1. 运行 `dbxt`，`↑` `↓` + `Enter` 选连接（`c` 新建）。
2. `↑` `↓` + `Enter` 打开表；侧栏直接打字即过滤。
3. `Tab` 到 SQL 编辑器输入语句，`Ctrl-J` 跑光标处、`F5` 跑整段。
4. 结果区 `e` 编辑单元格、`i` 插入、`Delete` 删除 —— 执行前展示完整 SQL。
5. `?` 打开当前栏迷你速查，`F1` 看全部键位。
6. 连接列表页顶部是今日 Tip，按 `T` 换下一条。

## 0.0.4 新特性

自首个预览以来最大的一次跃迁 —— 侧栏变成了真正的树，围绕生产连接的安全网也成型了。

- **连接树** —— 侧栏现在是 `连接 → 库 → 表`，`h`/`l` 折叠、按会话记忆（含 `3j`/`3k` 计数前缀移动）。
- **桌面端分组** —— DBX 桌面端的连接分组映射成树里的 `▾ 名称 [n]` 节点。
- **状态点 + 手动断开** —— 每个连接根带 `●` 活跃 / `○` 已断开 / `◐` 连接中；`x` 红色确认后断开池（不动配置）。
- **只读连接** —— 一个 `read_only` 标记在唯一收口拒绝所有写语句，`SELECT` / `SHOW` / `EXPLAIN` 照常。
- **历史直跑 + 收藏** —— `Alt-H` 召回，`Ctrl-Enter` / `p` 直接运行，`f` 把收藏固定在列表上方的独立分区；本次会话跑过的语句带青色 `●` 浮到最上方（内存 LRU 20，零查询、不落盘）。
- **结果钉住** —— `Alt-F` 把当前网格快照成一条置顶带，跨表对照。
- **补全上下文** —— `Alt-/` 在 `FROM` / `JOIN` 后只给表，在 `WHERE` / `ON` / `SELECT` 后只给列。
- **双击看行** —— 第二次点击打开行详情；确认按钮与树展开器也可点。
- **横向滚动条自动隐藏** —— 滚动后横条显示约 2.5 秒，随后边框恢复为一条素线。
- **快捷切库** —— `d` 一个手势切换 MySQL 库、PostgreSQL schema→库、MongoDB 库与 Redis 逻辑 db。
- **语句逐条跳转** —— `Alt-↓`/`Alt-↑` 在多语句脚本里逐条走（分号边界，字面量/注释跳过），状态栏给出 `语句 i/n` 锚点。
- **按当前列过滤结果** —— 结果区按 `*` 只留当前列含某值的行（预填当前单元格），与整行 `/` 搜索叠加。
- **状态栏显示服务器版本与连接延迟** —— 连接时一次性读活跃连接的服务器版本（单条免费元数据查询），终端 ≥56 列时显示；同一读取的耗时紧邻显示为 muted 的 `12ms`（超过 1s 显示 `1.2s`），链路慢一眼可见。探测失败什么都不显示 —— 不报错、不发第二条查询。打开表数据时，状态栏右侧最前还显示当前 `库.表`（窄屏 < 56 列只显示表名）。
- **结果单元格内查找（`\`）** —— 结果区 `\` 在当前页**所有单元格**里搜词，命中单元格全部标亮（当前命中用强调色）；`Enter` / `n` 下一个、`Shift-N` 上一个（循环），`Esc` 清除。与 `/`（隐藏不匹配行）不同，它不隐藏任何行；与 `g v`（只在排序列 / 主键列找）不同，它扫所有列。纯客户端、只扫已加载数据（**零查询**），上限 500 命中（`DBXT_CELL_FIND_LIMIT` 可调）。
- **括号配对高亮** —— 光标停在 `(`/`)`/`[`/`]`/`{`/`}` 上（或紧邻其后，与 `%` 同一规则）时，配对项自动高亮（青色 + 加粗）；**词法感知**（复用 `%` 的分词状态机：字符串字面量 / 注释里的括号不参与配对），且只扫光标附近 **±200 行**，大文件每帧开销与一行 SQL 相同。零键位、零查询、纯渲染。
- **单元格快速复制** —— 结果区 `Y` 复制当前单元格值到剪贴板（状态栏给出列名、取值与字符数，如 `✓ 已复制「name」= seven · 5 字符`）；`y` 仍是整行 `INSERT` 语句，`Enter`/`o` 行弹层里的 `y` / `Y` 是同一个“复制值”手势。Redis 值表格 / MongoDB 文档网格同样支持 `Y`。
- **侧栏快速搜索** —— `f` 跨分组搜连接 / 库 / 表名，只读**已加载的树缓存**（不发查询）。命中分组自动展开，`Enter` 跳到首个命中并清输入，`Esc` 仅清除；输入时光标就停在首个命中上。
- **树行就地重命名 / 排序** —— 连接根或分组行上按 `r` 就地重命名（`Enter` 保存、`Esc` 取消；空名 / 超长会双语提示）。连接重命名走**单条 upsert**，不重建整库、不动连接池与密钥；其余行 `r` 仍是表结构。`Shift`+`↑`/`↓` 在同层内上 / 下移动连接或分组，并把新顺序写回桌面 `sidebar_layout`。结果区 `<`/`>` 收窄 / 加宽当前列，**会话内记忆**（翻页 / 重新查询不丢，不落盘）。
- **补全自动加引号** —— `Alt-/` 只在名字需要时加引号（含大写、标点或保留字如 `order` / `key`），并按当前连接方言：MySQL 系反引号、SQL Server 方括号、其余双引号。全小写普通名不加。
- **只读连接处处可见** —— 只读连接的 🔒 除树根外还出现在编辑器标题与状态栏连接徽标上；拦截写语句时会带上连接名，如 `✗ 只读连接「prod」：拒绝写语句（DELETE）`。
- **列结构弹层加料：默认值 / 键标 / 就地过滤。** `g c` 现在多出两列 —— **默认值**（`=CURRENT_TIMESTAMP`）与**键标** `PRI` / `UNI`，非唯一索引首列标 `MUL`（取自表的索引元数据，弹层自身仍**零查询**）。终端够宽时弹层加宽到 96 列；窄屏优先保住列名 / 类型 / 键标可读，默认值允许截断。`/` 就地按列名过滤（输入即筛，`Enter` 保留、`Esc` 清除），40 列的大表也能一下定位；`j` / `k` 高亮一列后 `Enter` 直接跳到结果区该列。
- **当前语句高亮。** 多语句编辑器里，光标所在语句保持正常亮度，其余语句整段淡化（`;` 边界，字面量 / 注释里的分号不切分 —— 与 `Alt-↓` 同一套切分）。纯渲染零查询；缓冲 < 256 KiB 每帧全扫，超过则只扫光标 ±500 行。
- **按行号跳转（`:`）。** 结果区按 `:` 打开单行输入：填 1 基行号（`:40`）或 `$` 跳末行，`Enter` 跳转。查询结果、浏览的表、Redis / MongoDB 网格都可用，与既有 `gg` / `G` / `Home` / `End` 并存。超出范围的行号现在**钳到末行**（不再报错）；**分页表视图里行号是整表的绝对行**，按需加载目标页并把光标落到正确偏移。
- **一键打开 SQLite 文件（`L`）。** 连接选择器（或任意浏览区）按 `L` 打开文件选择器，从当前目录起步：输入路径、`↑`/`↓` 选择、`Tab` 补全（单个匹配直接补全，多个补全公共前缀）、`Enter` 打开；子目录就地进入，只列 `.db` / `.sqlite` / `.sqlite3` 文件。最近打开的 5 个文件列在选择器顶部，`Enter` 直连、`Del` 移除。打开的是**会话级临时连接** —— 本次运行内出现在连接列表，但**绝不写入连接配置**，重启不留幽灵连接。全程纯客户端，唯一查询是你之后自己发的。
- **SQL 收藏，可管理（`Ctrl-O` / `Alt-S`）。** 编辑器内 `Alt-S` 一步把当前 SQL 存为 DBX `saved_sql_files` 收藏（与 `Ctrl-O` 列表同一存储）。列表新增 `/` 过滤（匹配名称或 SQL 文本，大小写不敏感）、`d`/`Del` 红色确认删除，并限制每连接**上限 100 条** —— 超出时拒绝保存并提示先删，不会无限增长；空态直接说明如何添加。裸 `f` 仍是普通 SQL 字符，编辑器内一步收藏用 `Alt-S`。
- **内置 SQL 模板（编辑器内 `Alt-T`）。** 编辑器聚焦时按 `Alt-T` 打开只读模板面板，内置八条常用语句 —— `SELECT … WHERE`、`INSERT`、`UPDATE … WHERE`、`DELETE … WHERE`、`CREATE INDEX`、`ALTER TABLE … ADD COLUMN`、`TRUNCATE`、`DROP TABLE` —— `Enter` 把光标处模板插到编辑器光标位置。每条都带 `{{table}}` / `{{col}}` / `{{value}}` 占位符：插入后光标落在第一个占位符上并**选中**它，直接输入即替换，`Tab` 跳到下一个（可循环）；占位符未填完时以专属底色高亮，全部替换后 `Tab` 恢复切栏。`/` 按名称或 SQL 文本过滤，面板顶部标注分工：模板为内置只读，自存 SQL 见 `Ctrl-O` 收藏。插入是**纯文本、零连接、零查询**（只读连接同样可用）。编辑器之外 `Alt-T` 仍是数据搬运向导。
- **跳过空值（`}` / `{`）。** 结果区 `}` / `{` 把行光标移到当前列单元格非空的下 / 上一行（跳过 `NULL` 与空串）—— 稀疏列不再是一屏空白。状态栏给出绝对行号；`n` / `p` 仍是翻页。
- **编辑器内查找（`Ctrl-F`）。** `Ctrl-F` 在底栏打开输入框，边输入边在 SQL 缓冲区内查找 —— 大小写不敏感子串，**纯客户端（不发查询）**。所有命中高亮，状态栏显示实时的 `3/7` 计数；`Enter` / `F3` / `Alt-N` 跳到下一个命中（循环），`Alt-B`（支持的终端里 `Shift-Enter` / `Shift-F3` 也可）跳到上一个。`Esc` 关闭输入但**保留高亮**，可继续阅读；`F3` / `Alt-N` 仍可循环，下次编辑（输入、粘贴、插入片段）自动清除。Tab 与宽 CJK 字符按真实屏幕单元格高亮，光标跳到的那个命中用强调色，计数与屏幕一致。
- **半屏滚动（`Ctrl-D` / `Ctrl-U`）。** 编辑器内 `Ctrl-D` 半屏向下滚动、光标跟随可视区；结果区 `Ctrl-U` 半屏向上滚动，复用整屏（`PageUp` / `PgDn`）的滚动量算法，跨页衔接、到边界钳制。该动作**对既有绑定让位**：编辑器内 `Ctrl-U` 仍为撤销，**行选模式下 `Ctrl-U` 变为批量置值**（见下），结果区 `Ctrl-D` 仍为删除当前行（状态栏不动），各取空闲的那个键。纯客户端；结果网格滚动时表头始终钉在顶部。
- **同库表切换（`g b`）。** 数据视图里按 `g b` 打开一个**输入即过滤**的表切换浮层（复用最近表浮层的样式）：直接打字母筛当前库 / 模式的表名（匹配 `schema.table`，打 `inv.` 可整段收窄），`↑` / `↓`（`j` / `k` 同）选、`Enter` 打开该表数据、`Esc` 关闭。列表来自侧栏**已缓存**的表清单（**零查询**），视图 `~` 后缀与侧栏一致；侧栏 `/` 过滤不会把表从这里藏掉。
- **`g c` 回车跳列。** 列结构弹层里 `j` / `k` 高亮某列，`Enter` 直接把结果区的单元格光标跳到该列并关掉弹层（状态栏 `跳到第 N 列 …`）。列被列显隐隐藏（或查询结果里没有）时给出提示而不是乱跳；弹层自身仍**零查询**。
- **`g c` 列值分布。** 列结构弹层现在就地显示高亮列的分布 —— **非空 / 空 / 去重** 计数，去重旁附一段 **12 格方块 sparkline**（数值列按数值分桶，其余按值长度分桶；窄屏 < 56 列隐藏），数值列再加 `min` / `max` / `avg`。终端够宽时放在列表右侧独立栏，窄屏则堆在列表下方。全部**就地计算、绝不发查询**：没打开表数据时提示“打开表数据后可用”，超过 5000 行的页只统计前 5000 行并明确标注 `（按前 N 行统计）`。
- **状态栏补全库.表。** 打开表数据时，状态栏右侧上下文块最先显示 `库.表`（PostgreSQL 带 schema：`库.schema.表`；MySQL 的 schema 即库名时不重复）；连接名已在左侧徽标里，所以这里只补库段。窄屏（< 56 列）只显示表名，行 / 列读数照旧。
- **行详情弹层再进一步。** `o` / `Enter` 本就逐行列出 `列 = 值`；现在弹层内 `n` / `p` 也能上下移动（带计数前缀，`5n`），`/` 输入即按**列名或值**过滤，`y` / `Y` 都复制当前字段值（状态栏给出列名与字符数，与结果区 `Y` 同一条路径）。窄屏（< 56 列）每个字段改为 `字段:` 一行、值缩进一行堆叠，而不是把长名字和值挤在一行。全部就地完成，零查询。
- **`z` 处处有提示。** 钉住首列（`z`）现在在 Redis 值表格 / MongoDB 文档网格里也会闪出同样的双语文案（`首列已钉住 · z 取消` / `首列已取消钉住 · z 钉住`）—— 此前只有 SQL 结果区会提示，MongoDB 更是完全没有 `z`。
- **列宽能记住了。** 结果区 `<` / `>` 收窄 / 加宽当前列；浏览表时宽度现在会**写进 `~/.config/dbxt/tui.json`**，以 `(连接, 库, schema, 表, 列名)` 为键，下次打开同一张表自动恢复（普通查询结果仍只记在会话内）。`0` 丢弃当前列的记忆、回到按内容自适应宽度；`Alt-0` 清除当前表**全部**列宽记忆。列表上限 **200** 条、LRU 淘汰，配置不会无限膨胀。
- **按内容一键适配列宽（`g w` / `g W`）。** `g w` 一键把结果区当前列按已加载内容自适应：扫内存里的单元格（**零查询**），取显示宽度的 **P95**（去超长异常值——一条备忘录、一段 JSON 不会把整列撑开），多字节 / 宽字符按终端格宽计算，钳到 **6~40 格**。`g W` 对全部可视列（含钉住的首列）做同样的事；窄屏（< 80 列）只适配**可视的前几列**，手机端布局不会因此抖动。宽度写回手动 `<` / `>` 用的同一条记忆通道：浏览表跨会话持久化，查询结果只记在会话内。`0` 复位当前列，`Alt-0` 清空整表。
- **树上跳表（`g t`）。** 侧栏里按 `g t` 打开当前库的表切换浮层（与数据视图 `g b` 同一个**输入即过滤**浮层）：输入表名前缀收窄，`↑` / `↓`（`j` / `k`）选，`Enter` 打开，`Esc` 关闭。列表就是侧栏**已缓存**的表清单 —— **零查询**。
- **连接树快捷操作。** 树上的输入即过滤（`/` 或直接打字）现在一步到位：`Enter` 跳到首个匹配并**直接执行** —— 命中连接就切换连接、命中库就切库、命中表就打开；无匹配时状态栏给出双语提示，不再静默。`Alt-Shift-H` 打开**最近连接列表**（本会话连接过的连接，最多 8 个、最近在前；`↑`/`↓` 选、`Enter` 重连、`Esc` 关闭）；连接根 / 库 / 表行上按 `P` 发**一次最小健康探测**（`SELECT 1` / `PING` / `db.runCommand({ping:1})`），RTT（或失败原因）显示在状态栏 —— 失败绝不弹错误框。侧栏**分组折叠态**现在写入 `tui.json`，下次启动恢复。
- **`g c` 值分布加 sparkline。** 列结构弹层在去重数旁边多出一段 **12 格方块 sparkline**，按采样值画分布 —— 数值列按数值分桶，其余按值长度分桶 —— 全部**就地用已加载页计算（零查询）**。窄屏（< 56 列）自动隐藏，保证纯计数可读；终端够宽时弹层会稍微加宽，让计数与 sparkline 同时放下。
- **侧栏表信息卡（`i`）。** 把树光标停在表节点上按 `i`，弹出一张紧凑信息卡：类型、引擎、注释、列数 / 索引数、行数估算、数据大小、创建时间。每一项都只读**本会话已缓存的元数据** —— 树自己的表列表、已打开表的列元数据、以及库行按 `s` 得到的行 / 大小估计 —— 所以打开信息卡**绝不发查询**。尚未打开过的表优雅降级：只有打开才能填的字段显示“打开表后可用”，并在卡片末尾注明本表尚未打开。`Esc` / `q` / `i` / `Enter` 关闭。
- **`Esc` 现在会告诉你它做了什么。** 关闭浮层或清除结果过滤时，状态栏闪一条简短的双语文案 —— `已关闭列结构` / `已清除结果搜索` / `已回到侧栏` —— 并在 **1.5 秒**后自动淡出，按键不再静默、状态栏也不会留下过期文字。规则统一：浮层的 `Esc` 只关**最上面一层**（嵌套的单元格弹层先回到行弹层），结果集的 `Esc` 清除搜索 / 过滤高亮，编辑器的查找 `Esc` 保留高亮直到下次编辑。
- **大数字单元格可读性（`#`）。** 结果区按 `#` 在 **原样 → 千分位**（`1234567` → `1,234,567`）**→ 缩写**（`1.2M` / `3.4G`，千进制）三档间循环，状态栏闪当前档位。只处理**驱动报告为数字类型**的列，且整数部分 ≥ 6 位才生效；浮点只给整数部分加分隔符（`1234567.89` → `1,234,567.89`），`VARCHAR` 存数字、科学计数法一律不动。**纯显示层**：`Y` 复制与 `e` 编辑回填的始终是驱动返回的原值。默认关闭（数字按驱动原样显示），按 `#` 开启，档位写进 `~/.config/dbxt/tui.json`，下次启动沿用。
- **奇偶行斑马纹（`%`）。** 结果集奇数行用终端自身的 dim 属性轻微变暗，浅色 / 深色主题下都可辨、不刺眼；光标行与行选块覆盖它，绝不把当前行压暗。默认关闭（不铺底色，避免与所选行高亮混淆），`%` 开关并写入 `tui.json`（`stripe`）。纯渲染，零查询。
- **跳到执行出错的语句（`F8` / `Shift-F8`、`Alt-E`）。** 多语句脚本执行失败后，出错语句在编辑器里整段标红（当前所在的那条用更亮的强调色），光标自动落到第一条。状态栏保留错误信息并追加序号（如 `· 第 2 条语句`）；`F8` / `Shift-F8` 在多条失败间前后循环（首尾衔接），结果区里 `Alt-E` 同效。行号直接取自驱动自己的报错（MySQL `at line N`、PostgreSQL `LINE N:`），全程**纯文本定位、绝不发查询**。`F8` 在各区域都空闲；`Alt-E` 仅在已定位到错误时接管，否则仍是连接导出键。一旦编辑缓冲，高亮即清除。
- **单元格时间戳预览（`v`）。** 数字列的整型值落在 epoch 秒范围（`1e9`~`4e10`）时，`v` 弹层底部追加一行灰显的**本地**时间 + 相对时间 —— `🕒 2024-06-01 12:34:56 · 3 天前`。**只读预览**：值本身、以及 `y`/`Y` 复制的内容都不变，也不猜测时区语义（`VARCHAR` 里同样的数字串不动）。

- **全局快捷键，抬眼可见。** 每个上下文的 footer 现在预留一小段**全局段**（宽屏 ≥ 100 列时显示），列出该上下文最常用的全局手势 —— 编辑器显示 `Ctrl-O` 片段 / `Ctrl-P` EXPLAIN / `Ctrl-S` 提交，结果区与侧栏显示 `Ctrl-L` 切模式 / `Ctrl-A` 折叠栏 / `Tab` 切区；`?` 迷你卡尾行固定一条 `Ctrl-L 模式 · [ ] 标签 · F1 全部` 锚。全量帮助的「— 全局 —」分区补全为路由全局键的**完整清单**（含批量队列的 `Ctrl-T` / `Ctrl-S` / `Ctrl-X` 与 `Ctrl-D`）。**行选模式**下 `Ctrl-A` 全选本页（等价 Redis / Mongo 的 `a`）；**行详情浮层**里 `J` 在字段下方就地展开 JSON 对象/数组（带 `(J 美化)` 灰标）—— `y`/`Y` 始终复制原始值。全部客户端，零查询。
- **钉参照行对照（`g s`）。** 宽表横向滚过表头后，`g s` 把当前行钉为**参照行**：行尾出现轻量 `❮` 标记，状态栏显示当前行相对它的带符号偏移 —— `Δ+37`，并附上两行的**首个差异列名**（`Δ+37 (user_id)`，由已加载数据客户端计算）。再按 `g s` 取消；同时只允许一个参照行。换表 / 重查询自动清除；翻页跨过参照行时只在已加载窗口内显示标记（绝不发查询）。
- **冻结当前列（`g f`）。** `g f` 把当前列冻结到左缘，横向滚动时始终可见 —— `z` 只钉首列，这个键把同一能力扩展到任意列。总共最多冻结 **2 列**（与 `z` 的首列合起来计）；在已冻结列上再按 `g f` 即解冻，冻结列列宽仍可用 `<` / `>` 调。MongoDB 文档网格里 `g f` 保持 R82 的字段跳转（该网格 `g s` 同样钉参照行）。

## 功能特色

**连接管理** —— 与 DBX 桌面端共享
- 连接存放在 DBX 自己的 SQLite 存储（`dbx.db`）里，你在桌面端配置过的连接自动可见。
- `c` 在 TUI 内新建连接，`e` 编辑选中的连接（预填表单，含 SSH 隧道），`p` 复制到表单，`x` 删除连接（红色确认），`Enter` 连接；连接按数据库家族着色。
- 连接表单新增 `color` 行：`Space` 循环预设调色板（无色 → 10 色 → 自定义），`Enter` 输入自由 `#RRGGBB`，右侧色块实时预览。颜色写入 DBX 自己的 `color` 字段，与桌面端互通，编辑与复制全程保留，并贯穿侧栏、连接选择器、标题栏、状态栏与 `d` 切换层头部（颜色只作辅助，名称始终完整可读）。
- **快捷填写。** 表单字段按实际建档顺序排列 —— `db_type` → `name` → `host` → `port` → `user` → `password` → `database` → `query_timeout`，`Tab` 依次走过就是填写顺序。选定 `db_type` 会**自动带出默认端口**（MySQL `3306` / PostgreSQL `5432` / Redis `6379` / MongoDB `27017`）；一旦手动改过 `port` 就固定不再被覆盖。`name` 留空时保存会**按 `host-db_type` 自动生成连接名**（如 `localhost-postgres`），临时连接不必手填名字。
- **连接级查询超时。** `query_timeout` 行填秒数 —— 留空沿用内核默认（60s），`0` 表示**不限**，其它值即为该连接的查询上限。它写入 DBX 自己的 `ConnectionConfig::query_timeout_secs`（桌面端看到同一个值），并通过内核的超时通道传给每一次编辑器 / 表浏览查询；在 **PostgreSQL** 上还同时映射为连接级 `options=-c statement_timeout=…`，服务器对每个池内会话都生效，`SHOW statement_timeout` 能读到 —— **不逐条查询发 `SET`**。命中上限时 dbxt 会把裸 driver 报错改写成 `查询超时（30s），可调大超时或优化语句`，而不是把驱动原文抛给用户。
- 选择器里按 `s` 循环排序：**名称**（默认）→ **类型** → **颜色**，生产（红色）连接一键聚到一组。
- `d` 弹出切换层 —— MySQL 库、PostgreSQL（及其他支持 schema 的引擎）先 schema 后库、MongoDB 库、Redis 逻辑 db 同一套手势。
- `o` 返回连接选择，`r` 原地刷新列表。
- **直接打开 SQLite 文件（`L`）。** 在选择器（或任意浏览区）按 `L`，从当前目录选 `.db` / `.sqlite` / `.sqlite3` 文件：输入路径、`↑`/`↓` 选择、`Tab` 补全、`Enter` 打开；子目录就地进入。最近 5 个文件留在顶部（`Enter` 直连、`Del` 移除）。该连接是**会话级临时连接** —— 绝不写入已保存的连接配置，重启不留幽灵。
- **连接状态点 + 手动断开。** 侧栏每个连接根（以及 Redis 头部）都带一个状态点，**形状**区分状态 —— `●` 活跃（池在，可查）/ `○` 已断开 / `◐` 连接中 —— 点的颜色仍是该连接自己的颜色（身份），任何色觉下都能区分。断开后连接名变暗，已缓存的库 / 表仍以 muted 显示；展开它（或点它的某个库）会重新懒连接。连接根上按 `x` 弹出红色**断开**确认（`断开 conn-x？` —— 未提交的手动事务将回滚），走内核自己的用户断开路径 `remove_connection_pools`（先回滚手动事务会话，再关池，绝不裸 drain）。断开*当前*连接会把它收起为灰根，焦点移到最近的另一个连接根 —— 侧栏保持树形，不会闪出空屏。连接选择列表里 `d` 断开高亮连接，这也是 Redis 的入口（它的浏览器没有树根行）；MongoDB 与 SQL 一样在根上按 `x`。只清池，不动配置。

**安全阀** —— 为“一直开着生产连接”的场景准备
- **只读连接。** 表单新增 `read_only` 行（`Space` / `Enter` 切换）。开启后该连接**一切写语句硬拦截** —— `INSERT` / `UPDATE` / `DELETE` / DDL 全部拒绝，红色状态 `✗ 只读连接：拒绝写语句（INSERT）`；`SELECT` / `SHOW` / `EXPLAIN` / `DESCRIBE` / `VALUES` / `TABLE` 照常。判定是**语句级纯文本分析，零额外查询**：看首个关键字，`WITH …` 归约到顶层动词、`EXPLAIN` 剥掉外层（因此 `EXPLAIN ANALYZE DELETE` 仍算写）；拿不准的一律拦截（未知关键字、裸 `BEGIN`、会话 `SET` 都当写）。多语句批次（`SELECT 1; INSERT …`）整体拒绝。所有写路径共用一个收口（编辑器、`.sql` 文件脚本、历史直跑、行编辑/插入/删除、批量提交、红色确认层放行），并覆盖非 SQL 写入（CSV 导入、`Alt-T` 搬运的只读目标、Redis / MongoDB 写入）；侧栏连接根前缀 `🔒`（沿用连接色）。标记存于 DBX 自己的 `ConnectionConfig::read_only`，与桌面端互通。树上（或 Redis 键列表）按 **`!`** 切换当前连接的只读开关（红色确认层）：连接根的 `🔒` 与编辑器徽标即时出现 / 消失，并走同一条单条 upsert 落盘，重启后仍在。
- **两段式退出。** 编辑器里有未执行语句（或侧栏/结果过滤生效）时，第一次 `q`（或 `Ctrl-C`）只提示 —— `编辑器有未执行语句 · 再按 q / Ctrl-C 退出 · Esc 留下` —— 再按一次才退；`Esc`（或任意其他键）留下。编辑器为空/已执行时照旧一次退出。
- **危险语句影响面。** 红色确认层现在回显语句里每条 `UPDATE` / `DELETE` 的 `WHERE` 谓词原文（截断 80 列，如 `WHERE 谓词：id = 4821`），让“看着有边界”的写操作也能看清真正会作用的范围。`TRUNCATE`、`ALTER … DROP COLUMN` / `DROP CONSTRAINT` 加入 `DROP`、无 `WHERE` 的 `UPDATE` / `DELETE` 危险清单。`LIMIT > 10000` 的 `SELECT` **不拦截**，只落一条黄色 `⚠ 大结果集 · LIMIT 20000 · 可能较慢` 提醒。

**快捷查看与对照**
- **连接分组展现。** 桌面端（DBX Desktop）里给连接分过组的话，侧栏按同样的树展示：分组画成可折叠的 `▾ 生产 [2]` 节点（`[n]` 统计组内仍存在的连接数，含嵌套组），组内连接按桌面端自己的顺序排列，嵌套组再缩进一级。`h` / `l`（或 `←` / `→`）折叠 / 展开分组，规则与其他节点一致（vim-tree），折叠状态写入 `tui.json`、跨会话记忆；分组行上 `x` 无动作（组没有连接池），也不会再漏进表过滤。R47b 的状态点 / `🔒` / 连接色照常作用到每个组内连接根。组内没有任何存活连接（或过滤下没有命中）时不画该组；过滤命中组内任一连接则整组可见。库里没有 `sidebar_layout`（或 JSON 损坏）就全部平铺，与之前完全一致。布局走内核自己的 store 读取，一次开库读一次（桌面端改分组后，下次打开连接库生效）。
- **列结构弹层（`g c`）。** 结果区按 `g c` 弹出当前表列的紧凑可滚动列表 —— 列名、类型、键标（`PRI` / `UNI` / `MUL`）、默认值、`NOT NULL`、注释 —— 全部来自打开表时已缓存的元数据（**零额外查询**）。`/` 输入即按列名过滤，`j` / `k` / `PgUp` / `PgDn` 移动高亮，`Enter` 跳到该列（结果区单元格光标落过去、弹层关闭；列被隐藏时给出提示），`Esc` / `q` 关闭。高亮列还就地显示**值分布** —— 非空 / 空 / 去重计数，去重旁附 **12 格方块 sparkline**（数值列按数值分桶，其余按值长度分桶；窄屏 < 56 列隐藏），数值列附 `min` / `max` / `avg` —— 全部从已加载页客户端计算（绝不发查询）；无数据时给提示，超过 5000 行的页只统计前 N 行并标注。写 SQL 时对照列名类型不用再切到完整 `g d` 结构视图；查询结果（无表元数据）退化为结果网格的列名。
- **钉住结果区（`Alt-F`）。** 结果区按 `Alt-F` 把当前结果快照钉成顶部一条 `📌` 条，切到别的表（或库）后，钉住的结果留在上方、新数据在下方加载 —— 直接在终端里上下对照。再按 `Alt-F`（或切换连接 / 后端）解除。编辑器里 `Alt-F` 仍是格式化，二者不冲突。
- **上下文限定的补全。** `Alt-/` 原本补全表名 / 列名 / 关键字，现在候选严格按上下文 —— `FROM` / `JOIN` / `INTO` 后**只给表名**，`WHERE` / `ON` / `SET` / `SELECT`（以及 `(` 之后）**只给列名** —— 全走连接已有缓存元数据，不回库。弹层单列，终端 **< 40 列时只显示 5 条**（否则 8 条），小屏不会盖住正在写的 SQL。

**连接导入 / 导出 / 迁移（`Alt-E` / `Alt-I`）**
- `Alt-E` 把**全部**已保存连接导出为自描述 JSON 包（`format` / `version` / `connections[]`，默认 `~/dbxt-connections.json`）。**默认不含密码**；`p` 显式开启（红色明文警告确认），`y` 则复制 JSON 到剪贴板而不写文件。状态栏报告目标路径与条数。
- `Alt-I` 从文件路径导入，自动识别格式 —— dbxt 自有 JSON 包、DBeaver `data-sources.json`（标准路径 `~/.local/share/DBeaverData/workspace6/General/.dbeaver/data-sources.json`）、Navicat `.ncx` XML 导出。预览清单逐条列出（名称 / 引擎 / 主机 / SSH / 颜色 / 需补密码），标出同名冲突，并列出无法映射的驱动（跳过）。
- 同名策略可逐条或整批：`s` 跳过、`r` 覆盖（按 `name` 匹配，红色确认，先删原配置）、`b` 都存（名加 `-imported`）；`Space` 勾选该条、`d` 逐条循环策略、`Enter` 导入。所有写入都经 `LocalBackend`，导入后连接立即可用（照常用连接键验证）。
- **DBeaver** 的 provider / driver 映射到 dbxt 引擎（`mysql8`→`mysql`、`postgresql`→`postgres`、`mariadb`、`duckdb`、`mongodb`、`sqlserver` 等），`ssh-tunnel` 段转为真实 SSH 层。**Navicat** `.ncx` XML 用容错的手写标签扫描解析（子元素或属性均可）。两家的密码均以 dbxt 没有的密钥加密，因此**不解析** —— 导入后标「需补密码」，完成状态汇总计数。

**SSH 隧道（跳板机）**
- 在 DBX 桌面端配好的带隧道连接在 dbxt 里直接可用：dbxt 把 `transport_layers` 原样透传给内核，无需重新录入。
- 连接表单新增 `ssh_tunnel` 段：`ssh_host` / `ssh_port`（22）/ `ssh_user`，以及 `ssh_auth` 登录方式 —— `password`、`key`（密钥路径 + 口令）或 `agent`（SSH agent，可填 socket 路径）。
- `ssh_host` 支持 `~/.ssh/config` **别名**；由内核解析，含 `ProxyJump`（自动展开为多跳）。
- 隧道转发到连接自身的 `host:port`，表单以 `远端目标` 显示；需要改转发目标就改连接的 `host` / `port`。
- 首次连接未知跳板机弹出主机密钥指纹确认（`y`/`Enter` 接受并记住，`s` 仅本次会话，`n`/`Esc` 拒绝）。已接受的密钥写入 DBX 自己的 `<存储目录>/known_hosts`；`~/.ssh/known_hosts` 只读不写。
- 隧道失败按阶段明确报错：**SSH 认证失败**、**SSH 主机不可达**、**隧道已建立但远端数据库不可达** —— 密码错误、堡垒机地址错误、对端端口不通三者互不混淆。

**SQL 编辑与结果**
- 多行编辑器，shell 风格 `↑`/`↓` 历史（从 DBX 共享查询历史初始化）；有选区时 `F5` / `Ctrl-J` 都只跑选区，无选区时 `F5` 执行整段、`Ctrl-J` 执行光标所在语句。每次执行都会写回该共享历史（含连接、数据库、耗时与成功标记），因此回溯列表与 `Alt-H` 面板同样覆盖你在 dbxt 里跑过的语句。
- `Alt-/` 按上下文补全标识符（表名 / 列名 / 关键字，标注 `T`/`C`/`K`）；`Tab` 上屏。（`Ctrl-Space` 仍作兼容别名可用，但它与输入法切换冲突，故不再宣传。）
- `Alt-H` 打开**查询历史面板**（最近 300 条，最新在前）：重复语句**合并为一行并计数（`×n`）**，反复重跑也不会刷屏——该行显示最新一次的时间 / 耗时。每行显示时间、语句首行摘要、执行耗时（`12ms` / `1.2s`，仅当 dbxt 记录过）、来源小标（`编` 编辑器 / `脚` 脚本 / `直` 直跑）与来源连接。收藏条目置顶在 **收藏** 分节（`f` 切换时实时在两段间移动）。`↑`/`↓`/`PgUp`/`PgDn` 移动，`Enter` 回填到编辑器（光标到末尾），**`Ctrl-Enter` / `p` 直接执行选中语句**（走常规管线，多语句照跑；面板关闭，结果直接进结果区，状态栏带耗时——不用再回填→切焦点→执行三步），`f` 在 DBX `saved_sql_files` 中收藏 / 取消收藏，`y` / `Y` 复制整条语句，`Del` 经红色确认后删除单条（仅删历史，不动数据库数据），`/` 过滤历史（匹配**语句文本 / 来源连接 / 来源小标**，大小写不敏感子串；Enter 保留，Esc 清除）。光标处语句在列表下方自动换行预览。**本次会话中 dbxt 自己跑过的语句浮到最上方**，带青色 `●` 标记：dbxt 在内存里记录真正发到服务端的最近 20 条语句（LRU，重复语句去重上浮，跨分区/跨连接同栈），面板一打开就**零查询**即时显示（不必等持久化存储返回），且全程只读内存、不落盘。这些记录没有存储 id，`Del` 会拒绝删除（退出即清空），而 `Enter` 回填、`Ctrl-Enter` 直跑、`y` / `Y` 复制照常可用。
- `Alt-F` 格式化编辑器 SQL —— 关键字大写、主子句换行、`JOIN` 单独一行、缩进 2 空格、空白收敛 —— 字符串字面量、引号标识符、注释与函数名（`count(`）保持原样。再按一次将已格式化语句压缩回单行（幂等切换）；`Ctrl-Z` / `Ctrl-U` 一步撤销，`Ctrl-Y` / `Ctrl-R` 重做。状态栏会如实提示 `已撤销` / `没有可撤销的` / `已重做` / `没有可重做的`，撤销不再是静默无反馈。
- 编辑器保留 vim / readline 手感：光标在 `()[]{}` 括号上或旁边时 `%` 跳到配对括号（其余位置照常输入 `%`，`LIKE '%x%'` 不会被抢；字符串与注释里的括号不计入配对），`Ctrl-A`/`Ctrl-E` 到行首/行尾（`Home`/`End` 同），`Ctrl-K` / `Ctrl-Shift-K` 删至行尾，`Ctrl-W` 删前一个词。
- **回车自动缩进 / 括号自动补对（默认开）。** 在上一行以 `SELECT` / `FROM` / `WHERE` / `AND` / `OR` / `JOIN` / `ON` / `SET` / `VALUES` 或 `(` `[` `{` `,` 结尾、或该行含未闭合括号时按 `Enter`，新行继承上一行缩进**再加两空格**；纯空白行不继承，其余行只把自己的缩进传下去。输入 `(` 或 `[` 会自动补上 `)` / `]` 并把光标停在中间；光标处已是相同的右括号时按 `)` / `]` 直接跳过而不重复输入。两者都是纯客户端编辑行为 —— **不发查询、不改显示** —— 且都走 SQL 词法器，字符串字面量、引号标识符或注释里的括号/关键字绝不当代码处理。各自在 `~/.config/dbxt/tui.json` 有独立开关（`editor_indent` / `editor_pairs`，默认均为 `true`；写 `false` 只关掉对应那一项）。
- **语句序号栏（`F2`，默认关）。** 打开后编辑器左栏保留一条细 gutter，在每条语句首行标出 `1.` `2.` …（与 `Ctrl-J` / `Alt-↓` 同一套分号切分），长脚本一眼看清语句边界。**纯渲染层 —— 绝不改动 SQL 文本**；开关存入 `~/.config/dbxt/tui.json` 的 `stmt_gutter`，跨会话记住。缓冲超过 256 KiB 时该帧不画序号（避免每帧跑词法器）。
- **编辑器内查找（`Ctrl-F`）。** 底栏输入关键词，边输入边高亮缓冲区内所有命中 —— **大小写不敏感子串，纯客户端**（绝不发语句）。`Enter` / `F3` / `Alt-N` 跳下一个命中，`Alt-B`（支持的终端里 `Shift-Enter` / `Shift-F3` 也可）跳上一个，均循环；状态栏显示当前位置 `3/7`。`Esc` 关闭输入但保留高亮，命中继续可读，`F3` / `Alt-N` 仍可循环，下次编辑自动清除。当前命中用强调色、其余用普通标记，Tab 与宽 CJK 字符按真实单元格高亮。`Ctrl-F` 仍是结果区的翻页键；只在编辑器获得焦点时归编辑器。
- **注释切换与编辑器剪贴板环。** `Ctrl-/` 在选区或光标所在行上加 / 去 `-- ` 行注释 —— 保留缩进，多行选区逐行处理（不使用 `/* */` 块注释），已是真实注释的行精确去掉一个 `--`（及随之的一个空格）。跨多行字符串里续行的 `--` 不参与判断：复用 SQL 词法边界，被引号包住的 `--` 不会被当成注释。切换后整段保持选中，再按一次即可还原。不同终端对 `Ctrl-/` 的编码不一致（扩展键盘协议报 `/`；老终端发 `0x1F`，crossterm 记作 `Ctrl-_` 或 `Ctrl-7`），三者都接受；编辑器内另有 `Alt-C` 备用键（其他区域仍是紧凑列宽）。另外 `Ctrl-Shift-V` 从内存中的**剪贴板环**（最近 5 次编辑器内复制 / 剪切内容）粘贴，替换当前选区或在光标处插入并保持选中，连按即可循环翻到下一条；有选区时 `Ctrl-C` / `Ctrl-X` 复制 / 剪切入环（无选区时仍分别是退出 / 清空批量队列）。该环仅存活于本次会话、不落盘，也不读写 `Y` / OSC 52 系统剪贴板通道。
- **行详情字段定位与数值快照。** 行详情浮层（`Enter` / `o`）内 `\` 按**列名或值**定位字段 —— 命中项行首显示低调 `›` 标记，`n` / `N` 循环跳转，`Esc` 清除标记（再按一次 `Esc` 关闭弹层）。字段本身从不被隐藏：`\` 是 `/` 的**定位**孪生键（`/` 仍是收窄过滤），两者切换时互相清空（开一个即清另一个）。结果区里 `S` 开关状态栏**数值快照**：选中数值列时显示 `min 12 · max 98 · avg 45.3`（仅扫已加载窗口，列光标移动即重算）。NULL、空串、千分位文本（`1,234`）会跳过 / 解析，无数值的列不显示。`S` 是 `s`（排序）的大写孪生键；快照**默认关闭**、仅本次会话 —— 它改变状态栏常驻内容，属视觉变化 —— 两个手势全部纯客户端、零查询。
- `Alt-G` 打开**全库搜索**：在当前数据库（PostgreSQL 还含当前 schema）的所有 `char` / `varchar` / `text` 列中大小写不敏感地搜索一个词，命中以 `表.列 → 值` 列出并高亮匹配片段。每张表执行一条带 `LIMIT` 的 `SELECT`（`DBXT_SEARCH_SCAN_LIMIT`，默认 1000），估算行数超过 `DBXT_SEARCH_MAX_ROWS`（默认 1,000,000）的表会跳过并标注。`↑`/`↓` 移动，`Enter` 跳到该表并定位到命中行，`y` 复制命中值，`r` 重搜，`Esc` 中止正在进行的扫描（保留已扫描的部分结果）。仅支持 MySQL / PostgreSQL。
- `Alt-L` 加载并执行 **`.sql` 文件**：输入路径（开头 `~` 会展开），确认预览（文件大小 / 语句数 / 目标连接与库，下方是脚本预览）。超过 2 MB 给警告；含 `DROP`、`TRUNCATE` 或无 `WHERE` 的 `UPDATE`/`DELETE` 的文件会先走红色确认层。整个文件作为一条历史记录收录，结果即常规的分语句脚本汇总（错误信息内联）；`e` 可将文件载入编辑器。
- 每次执行保留独立结果标签（`[` / `]` 切换）；显示耗时与受影响行数。结果区顶部有一条**标签栏**，每个标签显示 `序号:语句前 12 字符`，当前标签高亮；终端过窄时自动把中间标签折叠为 `…`，当前标签始终可见。`Alt-W` 关闭当前结果标签（最后一个不可关闭；有未确认编辑时提示先处理；纯客户端，不发查询）。
- `Ctrl-P` 执行 `EXPLAIN`，`Ctrl-Y` 导出当前结果（CSV / JSON / NDJSON / Markdown / INSERT），`Ctrl-N` 在结果被行数上限截断时加载更多。
- `Ctrl-O` 插入 DBX 收藏片段；`s` 把编辑器 SQL 存回共享收藏库，`Alt-S` 在编辑器内一步完成同样的事，`/` 按名称 / SQL 文本过滤列表，`d` 经红色确认删除收藏，且每连接**上限 100 条**（超出时拒绝保存并提示先删）。
- 多语句脚本（`a; b; c;`）批量执行，逐条列出结果；执行中状态栏按条计数（`3/7`），完成后汇总带总耗时；`Enter` 下钻单条。

**表格数据与编辑**
- 侧栏 `Enter` 执行分页 `SELECT *`；`↑`/`↓` 连续走行并跨页自动衔接，`n`/`p` 翻页时保持相对行号。每次翻页都在状态栏就地刷新所加载的**绝对行区间**（`加载 big 第 3 页…（第 101-150 行）`），深页一眼看得出是第几批。
- 侧栏表列表边输边筛：任意可打印字符一步直接进入大小写不敏感的子串过滤（`/` 打开空过滤），`Enter` 跳到首个匹配并**直接执行**（命中连接 / 库则切换、命中表则打开，无匹配时状态栏双语提示），`Ctrl-U` / `Alt-Backspace` 清除；首字母跳（`Alt`+字母，再用 `;`/`,` 前后循环）在长列表里快速跳过；`s` 循环 名称 / 类型 排序（在库行上 `s` 改为惰性拉取该库尺寸——见下）。
- 侧栏是一棵**连接树**：`连接 → 库 → 表` 三级缩进（DBeaver 式），`h`/`l`（或 `←`/`→`）按 **vim-tree 语义**折叠 / 展开：展开的节点先原地收起，再按一次回到父层；`l` 打开收起的节点后再进首个子项 —— 分组 / 连接 / 库 / 表规则一致。树光标把**整行**填到侧栏右缘，选中哪一行一眼可见。`Enter` 打开（连接=切换并展开、库=切到该库、表=浏览数据），折叠状态在会话内记忆（分组折叠态写入 `tui.json` 跨会话）。展开非当前连接会**懒连接**并异步列出它的库（失败显示错误行，不影响整棵树）；`j`/`k` 在整棵树上移动（计数前缀 `3j`）。过滤器命中表名或库名时保留其父节点；`[`/`]` 快速切库。**库行上按 `s`** 惰性拉取该库聚合大小（`2.1 GB`；MySQL 走 `information_schema` 的 `SUM(data_length+index_length)`，PostgreSQL 走 `pg_database_size`）与当前库各表的行数估计（`table_rows` / `reltuples`）——结果会话内缓存、右对齐 muted 色、终端 <56 列自动隐藏，且绝不在启动或后台自动扫描。连接行上按 **`Y`** 一步复制该连接（不走表单）为新名字 `xxx-copy`，密码与 SSH 隧道一并复制，新根立即出现在树里。每个连接根还带 R47b **状态点**（`●` 活跃 / `○` 已断开 / `◐` 连接中，沿用连接色），按 `x` 可断开（见上文连接一节）。连接根或分组行上按 **`r`** 就地重命名（`Enter` 保存、`Esc` 取消）；**`Shift`+`↑`/`↓`** 在同层内上 / 下移动一项，并把顺序写回桌面分组布局（顶层未分组连接仍随选择器按名称排序）。
- 连续翻页在有主键时优先走 **keyset（主键续读）**：下一页是 `WHERE pk > last ORDER BY pk LIMIT n`，上一页反向 seek，因此翻页耗时不再随页码增长（千万级表的首页与第 2 万页都在毫秒级）。不是正好相邻一页的跳页、无主键表、以及对非主键列的排序仍走经典 `LIMIT … OFFSET`。未显式排序时按主键排序，使页边界确定（无主键表保持引擎自然顺序）。
- 行数按 `库.schema.表` + 过滤条件在会话内缓存。大表首次加载最多采样 `DBXT_COUNT_SAMPLE_LIMIT` 行（默认 50 万），超过就显示 `>500000 行`，不再每页做全表 `COUNT(*)` 扫描；设 `DBXT_COUNT_SAMPLE_LIMIT=0` 可恢复始终精确计数。小表仍显示精确总数。
- `←`/`→` 移动单元格光标，`}`/`{` 跳到当前列单元格非空的下 / 上一行（跳过 `NULL` / 空串），`Home`/`End`（及 `gg`/`G`）直跳**首行 / 末行**并把单元格光标回第一列，`z` 钉住首个数据列，`Enter`（或 `o`）弹出**整行**的纵向 `列 = 值` 列表 —— 看某一行从这里进，标题带主键定位（`第 12 行 · id=4821`）。行弹层内 `↑`/`↓`/`j`/`k` 或 `n`/`p`（可带 vim 计数，`5j`）移动选中列，`/` 按列名**或值**过滤（宽表 40+ 列找列），`y`/`Y` 复制当前列值（状态栏带列名），`Enter`/`v` 下钻完整单元格（窄屏 < 56 列时每个字段改为 `字段:` 一行、值缩进一行堆叠）；`Esc` 依次 单元格 → 行弹层 → 表格。表格里直接按 `v` 仍是完整单元格；底部条显示横向位置（细虚线滚动条仅在横滚后约 2.5s 内显示 —— 滚轮 / 滑动 / `◀`/`▶` / 跳列触发 —— 静止时自动隐藏，边框恢复为一条素线）。**超过 40 字符的长值在网格里缩略**为首 38 列 + `…`，避免一个宽列挤掉邻居；`v` / 行弹层仍显示**完整**值；真正的 `NULL` 保持灰色斜体 `NULL`（不用 `∅`）。
- **JSON 单元格美化。** `v` 打开的单元格若值是 JSON **对象或数组** —— PostgreSQL `json`/`jsonb`、MongoDB 文档里的嵌套字段、Redis hash 值里存的 JSON —— 自动缩进美化：**只做缩进 + 换行**。`J` 在美化 / 原值间切换（非 JSON 会提示），`y`/`Y` 复制的始终是**原始值**，不会复制缩进格式。标量（`42`、`"x"`、`true`）或非 JSON 文本原样显示，`v` 绝不擅自重排它看不懂的内容。含 `\uXXXX` 转义的值还会在弹层底部灰显一行**解码结果**；`U` 让正文在**原文 → 转义解码 → 整值重新转义**间循环（非 ASCII 全转 `\uXXXX`；纯 ASCII 值只有原文 / 解码两态）—— 解码失败（如孤立代理对）只报错、不改数据，`y`/`Y` 仍复制原始值。
- `e` 以 diff 确认层编辑单元格：旧值 → 新值、`WHERE` 条件、主键与完整 `UPDATE` 一目了然。
- `i` 按列模板插入，`Delete` / `Ctrl-D` 以带条件的 `WHERE` 删除 —— 所有写入先经确认。
- `Ctrl-T` 排队写入，`Ctrl-S` 以单个 `BEGIN … COMMIT` 执行；`f` 过滤、`s` 排序、`Ctrl-K` 追加排序键、`Ctrl-R` 清除。
- `y` 把当前行复制为 `INSERT INTO … VALUES (…)`；`/` 搜索可见结果行（隐藏不匹配行），`\` 在当前页**任意**单元格里找词（命中全部标亮，`Enter`/`n`/`Shift-N` 循环，`Esc` 清除；从不隐藏行），`gv` 则在排序列 / 主键列内定位值、不隐藏任何行（`n`/`N` 循环命中）；`|` 在宽表上按列号或列名前缀把单元格光标跳到该列。
- `V` 在结果网格进入**行选模式**：`↑`/`↓` 移动锚点，`Shift`+`↑`/`↓`（或 `v`/`V`）扩展选区，`Ctrl-A` 全选本页，`Ctrl-U` 把当前列批量置为同一个值（见下），`Esc` 退出；选中行整行反色显示为一条实心带。`Y` 把选区复制为 TSV（含列头），`d` 生成 `DELETE … WHERE pk IN (…)`（复合主键则为 `OR` 链）、`c` 生成 `UPDATE … SET … WHERE pk = …` 模板 —— 两者都只送进编辑器待人工确认，**绝不执行**（零写库红线）；无主键的结果（表达式 / 聚合 / 无主键表）会提示「无主键，跳过」。
- **批量置值（行选模式 `Ctrl-U`）。** 选中一段行后，`Ctrl-U` 为**当前列**弹出单行值输入条：输入新值即实时预览生成的 `UPDATE 表 SET 列 = <值> WHERE 主键 IN (…)`（整个选区一条语句；复合主键回退为可移植的 `(k1 = … AND k2 = …) OR (…)` 链）。值按该列的**声明类型**包装 —— 数值列裸字面量、文本列加引号并把 `'` 翻倍、留空（或 `NULL`）为 SQL `NULL`；用 `'…'` 可强制当字符串。`Enter` 把语句交给红色**确认层**，确认层双语显示**影响行数**，只有再确认才执行（只读连接在弹条前即被拦截）。输入过的值按表按列记忆：输入条内 `↑`/`↓` 取用最近 3 个模板（`Del` 清除高亮那条，或清空该列全部记忆，落入 `tui.json`），执行后的语句进入 `Alt-H` 历史。单条语句最多命名 **200** 行：超出会截断到前 200 行，并在语句与确认层同时给出截断提示。

**表结构**
- `r` 显示字段列表（类型 / 键 / 可空 / 默认值 / 注释）；`t` 切换按方言生成的 `SHOW CREATE TABLE` DDL。
- `Alt-D` **对比两张表结构**：当前聚焦的表为源，再选目标表（按 `c` 可换到**另一个连接**，从而跨库 / 跨方言对比）。浮层逐列给出 `+`（目标缺少，需新增）/ `-`（目标多余，需删除）/ `~`（属性不同：类型 / 可空 / 默认值 / 注释 / 字符集 / 排序规则 / extra / 主键 / 唯一），第二个标签页列索引（名 / 列 / 唯一 / 过滤条件），两侧引擎不同时标题带 `⚠ 跨方言`。类型比较是方言感知的：同引擎忽略展示宽度（`int(11)` = `int`），跨引擎按常见映射归一（`varchar(255)` ≈ `character varying(255)`、`int` ≈ `integer`、`tinyint(1)` ≈ `smallint`、`jsonb` ≈ `json` ……）；映射表外的类型标 `?` 并原样展示两侧。
- `y` 复制纯文本差异摘要（可贴进工单）；`g` 生成把**目标**改写为源的 `ALTER` 脚本（`ADD` / `DROP` / `MODIFY`，含索引，PostgreSQL 另有 `COMMENT ON COLUMN`）—— dbxt **绝不执行**，只在一个预览标签里展示，你可复制到别的客户端或编辑器运行。
- `Shift+Alt-D` 对比两个**库的表清单**（仅源 / 仅目标 / 共有）；`Enter` 落在共有的表上进入单表对比。生成的语句按方言加引号（MySQL 反引号、PostgreSQL `"双引号"`）。
- `Alt-K` **对比两张表的数据** —— 结构对比的行级续作（在对比浮层里按 `m` 可在 结构 ↔ 数据 间切换）。选择目标表（按 `c` 可换到**另一个连接**，从而 MySQL ↔ PostgreSQL 对比），可选输入两边同时生效的 `WHERE`（`w`）。两表都有主键时用它做行对齐的键，列按列名交集对比，列序不同不影响；两边都**没有主键**时退回**行序对齐**，各取前 500 行（行号 `#1`、`#2`…），且因缺少唯一定位键而不生成同步语句。主键对比在后台按每块 1000 行流式拉取（先 `COUNT(*)` 预报规模；`Esc` 可中止并保留已比结果；差异行超过 5000 条时截断并提示缩小范围）。浮层汇总显示 源 / 目标 行数、仅源 `<` / 仅目标 `>` / 差异 `≠` 计数与 `已比 N 行`；`Tab` 切到这三个明细列表，`n` / `p`（或 `j` / `k`）在差异行间跳转，`Enter` 把 `≠` 行展开为列级左右对照。值按文本比较，跨方言用 canonical 映射归一（`1` = `1.0`、`true` = `1`、`2026-01-01T…` = `2026-01-01 …`）；映射表外的类型原样比较并标 `?`。`y` 复制纯文本摘要，`Y` 把差异行复制为 CSV（`mark,key,column,source,target`，字段按 RFC4180 转义），`Ctrl-E` 把该 CSV 导出到临时目录的 `dbxt-diff-<时间戳>.csv` 并在状态栏显示路径；`g` 生成 源 → 目标 的同步脚本（`INSERT` / `UPDATE` / `DELETE`，值按目标方言转义）到预览标签 —— dbxt **绝不执行**。
- `Alt-T` **把一张表的结构和/或数据搬到另一个 SQL 连接**（迁移 / 备例 / 给测试库灌数）。三步向寻：① 选目标连接（默认当前连接，因此 MySQL → PostgreSQL 双向都行），② 改目标库 / 模式 / 表名（默认同名；改名即表复制），③ 选模式 —— **建表+搬数据**（默认）/ **仅建表**（结构）/ **插入已有表**（append）—— 以及选项。目标表已存在时 dbxt 默认报错停下（绝不静默覆盖）；`o` 切到**覆盖**，因会先执行 `DROP TABLE`，必须过红色确认层。选项：`w` WHERE 子集、`l` LIMIT 上限、`i` 带索引、`a` 带自增值（MySQL）或建 `serial` 列（PostgreSQL）、`s` 出错 停止报行号 / 跳过继续。搬运按源 keyset 分成 1000 行/块（无主键则退回 OFFSET），写入目标 500 行/事务批量；类型走与结构对比同一张跨方言映射表（包括 `bytea`/`blob`、数组与按目标方言转义的字符串）。源预估超过 100 万行时会多问一次 `Enter`；单批失败重试 1 次；状态栏实时显示 行数 / 块数 / 行每秒。`Esc` 中止并**保留已提交批次**，报告断点主键。完成汇总显示 源行数 / 已搬 / 跳过 / 耗时 / 速率 / 目标；`g` 复制摘要，`b` 在当前连接上直接打开目标表。Redis / MongoDB 不在范围（文档模型映射另议）。

**导入与导出**
- `I` 把 CSV 导入当前表（已浏览的表，否则侧栏选中的表）。输入路径（开头 `~` 展开为 `$HOME`）后确认预览：编码、分隔符、行数与文件大小、前五行解析结果，以及按列名对齐的列映射与类型推断（`int` / `float` / `bool` / `date` / `datetime` / `text`）。
- CSV 表头按列名（忽略大小写）匹配表列；CSV 中缺失的表列保留其默认值（通常为 `NULL`），多出的 CSV 列则阻止导入并给出明确提示。
- `m` 切换追加 / 覆盖（覆盖先清空表，预览边框变红），`s` 切换遇错停止（默认，报告出错行号）/ 跳过继续（列出所有跳过行）。数据以每批 500 行的事务批量写入，并按批报告进度。
- 自动探测编码 —— UTF-8，否则 GB18030/GBK（常见中文编码）—— 并从表头嗅探分隔符（`,` / `;` / TAB）。明确不支持 Excel `.xlsx`。
- `Ctrl-Y` 把当前结果导出为 CSV、JSON（数组）、NDJSON、Markdown、`INSERT`（每行一条）或批量 `INSERT`（多行 `VALUES`）。先选格式再选去向：留空走 OSC 52 复制，输入路径则写文件；超过 10000 行会提示生成可能耗时。

**Redis**
- 连接 Redis 后打开分页 `SCAN` key 浏览器（绝不 `KEYS *`），带类型与 TTL 徽标、服务端 `MATCH` 模式（`/`）与逻辑 db 切换。
- key 列表与 SQL 侧栏同一套快捷手感：任意可打印字符一步开启**子串过滤**（命中高亮，`Enter` 打开首位，`Esc` 清除），`Alt+字母` **首字母循环跳**（`;`/`,` 前后重复），`1-9` 直跳第 N 个 key，`3j`/`3k` 计数移动。
- `Enter` 按类型渲染 value —— string、hash、list、set、zset、stream、RedisJSON，大集合可继续加载；`y` 复制当前值，`Esc` 返回列表。
- 窄屏下类型徽标与 TTL 融合为单 token（`S·12s`），key 行不换行。任意宽度下 TTL 都在行尾紧凑显示 —— `45s` / `5m` / `2h` / `3d`，`-1` 永久、`-2` 不存在 —— 用的是 `SCAN` 页已带回的值，每秒本地倒计时。
- `e` / `x` / `m` / `Del` 编辑、设 TTL、重命名、删除；`Space` 多选后批量删除 / 设 TTL / 前缀重命名，均走红色确认层。
- **`T` 就地给焦点 key 设 TTL**（不必先打开 value），同样走红色确认层：默认按秒，可加 `s` / `ms` / `m` / `h` / `d` 后缀（`500ms` 用 `PEXPIRE`，`-1` 持久化，`0` 立即删除）。只读连接直接拦截；成功后已加载行的 TTL **就地更新**，SCAN 游标与页位置不动。
- **`t` 在已加载 key 上循环类型过滤** —— 全部 → string → hash → list → set → zset → stream；**`Ctrl-T` 按 TTL 排序已加载 key**（扫描顺序 → 升序 → 降序）。两者都是对已加载窗口的纯本地视图（零查询），当前过滤 / 排序回显在浏览器头部行。
- 其他功能仍可用原生 `redis-cli` 命令台（`Ctrl-L`）。

**MongoDB**
- 连接 MongoDB 后列出 collection；`Enter` 以网格浏览文档（顶层字段并集，`_id` 优先）。集合列表与 SQL 表列表共用 子串过滤 / 首字母跳 / 直跳 键位。
- `n`/`p` 翻页，`f` 应用 JSON 过滤，`r` 查看 collection 索引。
- **`g f` 跳到首个含该字段的已加载文档** —— 字段名可以是顶层名或点路径（`a.b.0`），全部在已加载页内客户端完成，不发查询。每行行尾多一列 `size(B)`，即该文档紧凑 JSON 的字节长度；**`Ctrl-S` 按文档大小给已加载页排序**（原始顺序 → 大小降序 → 大小升序，且能精确还原原始顺序）—— 纯本地视图，当前排序回显在网格标题上。
- **`c` 按点路径提取焦点文档的子值**（`a.b.0.name`）并走同一条剪贴板通道复制；路径不存在时在状态栏双语报错，而不是静默失败。文档网格与 `Enter` 行弹层里都可用。
- `e` 用 JSON 编辑器编辑文档（`_id` 不可改，字段级 diff），`i` 插入，`Del` 按 `_id` 删除 —— 每次写入确认并原地刷新。

**空态引导**
- 每个空列表都给出下一步动作，不再是无提示的死胡同：连接选择器显示 `还没有连接 · c 新建`，MongoDB 空页显示 `无文档 · f JSON 过滤 · i 插入文档`，零行结果显示 `0 行 · 修改 SQL 后 Ctrl-J 重新执行`（浏览表则是 `f` 改过滤 / `Ctrl-R` 清除）。Redis key 浏览器与无表侧栏本来就有提示。

**效率与体验**
- 任意位置 `?` 打开**当前上下文迷你速查**（单屏放下，不滚动）；编辑器 / 命令输入里 `?` 是字面字符，改用 `F1` 打开同一浮层。再按 `?`（或在小浮层按 `F1`）进全量速查。底部提示条按终端宽度分级显示（窄屏 4 个 / 中屏 6 个 / 宽屏全量，隐藏时显示 `? 更多`）。全量速查以 **`— 当前上下文 —`** 区块开头（当前界面的键位排前 —— 结果区即 `v` / `Y` / `*`），宽屏每行并排两列键位/说明；窄于 56 列自动改回单列。面板内按 `/` 可按**键位或功能名**过滤（中英文皆可，输入分区名如“结果”会带出整组）；`Enter` 保留过滤，`Esc` 清除。所有浮层统一 `Esc` 关闭。
- 列表支持数字直跳与计数前缀：侧栏 `1-9` 直跳第 N 个连接/表，`3j`/`5n` 在侧栏 / 结果 / 历史中重复移动或翻页；结果区 `gd` 看表结构、`gt` 回表数据、`gv` 定位值、`|` 跳列。
- `Alt-1..9` 直切第 N 个连接（按侧栏连接顺序），`Alt-Tab` / `` Alt-` `` 在当前连接与上一个之间对切（`Alt-Shift-H` 列出本会话最近连接，`Enter` 重连）；切换时智能恢复上次的库/表 —— 新连接有同名库表则直达，否则落在库列表首屏，状态栏提示落点；编辑器里有未提交内容时提示一次，绝不静默丢弃。
- 编辑器选中一段（`Shift`+方向键）后 `Ctrl-J` 只执行选区（有选区时 `F5` 同样只跑选区）；无选区时按分号执行**光标所在语句**（字符串 / 注释里的分号不算 —— 复用 `%` 配对括号的同一套词法状态机；光标停在语句间空隙则取**下一条**）。`F5` 执行整段，`Alt+Enter` 也执行光标处语句。选段执行**保留选区**，状态栏标出实际执行的语句（`执行第 N 条`）；失败时红色高亮只落在本次执行的语句上，`F8`/`Shift+F8` 只在本次范围内循环 —— 全程纯客户端切片、零额外查询。`Alt-P` 打开片段收藏并插到光标处（一步），`Ctrl-O` 仍是追加到末尾。
- `Ctrl-A` 自动折叠非焦点栏，`Ctrl-W` 收起 / 展开当前栏；低于 50 列时各栏纵向堆叠。横向布局下侧栏宽度自适应：按最宽的 `库.表` 名收窄（不低于可读下限，宽屏仍保留 28 列），把让出的列还给数据区；名字过长则截断并以 `~` 标记。
- `Alt-C` 压缩列宽，`Alt-V` 隐藏列，`Alt-R` 直达最近表（浮层内 `s` 在「按最近」/「按表名」间切换排序），`Alt-H` 打开查询历史 —— 选择按 `库.表` 持久化。
- `Alt-←` / `Alt-→` 像浏览器的后退 / 前进一样在最近 50 个节点之间往返 —— SQL 表、MongoDB 集合、Redis key 同级都是导航节点（value / 文档详情不进栈，后退会回到打开它的列表项）；打开新节点会截断前进分支，跨库切换同样可用。状态栏以 `← 表名` 确认落点；侧栏 `t` 浮层仍列出最近 5 张供直接跳转。
- 多语句输出兼具控制台手感：`Home`/`End` 与 `gg`/`G` 直达语句列表顶 / 底，错误行 `Enter` 打开错误框，`y` 复制当前语句结果为 CSV（与 `Ctrl-Y` 导出的首选格式一致），`Alt-O` 开关语句分隔线 + 紧凑耗时前缀（`12ms`、`1.23s`，默认关；`Alt-T` 已被数据搬运占用，故用 `Alt-O`）。
- 鼠标与触屏可用：点击选中、再点确认；同一位置 **400ms 内双击**（不报 Up 的终端 tap-tap 同样）打开整行详情 —— 即鼠标版 `Enter`。行弹层内单击某值把光标移过去、双击下钻完整单元格；侧栏 `▶`/`▼` 图标直接折叠 / 展开连接或库（不必先选中该行）；确认弹层 `[ Enter/y 执行 ]` / `[ Esc/n 取消 ]` 按钮可点（对应 `Enter` / `Esc` 两条分支），错误弹层点一下展开、长错误逐页下翻，翻到底再点关闭；编辑器点击即聚焦并把光标落到点击处（含横滚偏移；点在文本下方 = 跳文末）。滚轮滚行，`Shift`/`Alt`/`Ctrl`+滚轮横滚列。
- 失败可见：看门狗把无响应的后端变成错误，执行中显示转圈与已用秒数，服务端错误原样回显。
- 大结果集不卡：20,000×12 表格滚动约 0.6 ms/帧（列宽缓存 + 只切片可视窗口，不再每帧重扫全部行）；文件导出在后台任务里逐块直写磁盘 —— 20,000 行 × 12 列不到 1 秒，内存峰值只相当于一行（整进程约 36 MB，而把整个文档留在内存时约 96 MB）。
- 所有界面文案来自同一张表（`src/ui_text.rs`）；默认中文，`DBXT_LANG=en` 切换英文。

## 安装

一键脚本 —— bash（Termux 同样适用）或 PowerShell：

```bash
curl -fsSL https://raw.githubusercontent.com/vst93/dbxt/refs/heads/master/cmd/install.sh | bash
```

```powershell
irm https://raw.githubusercontent.com/vst93/dbxt/master/cmd/install.ps1 | iex
```

国内加速：把地址换成 `https://cdn.jsdelivr.net/gh/vst93/dbxt@master/cmd/install.sh`（或 `.../install.ps1`）。脚本从 GitHub Release 读取版本、校验 `.sha256`，安装到 `~/.local/bin`（Termux 为 `$PREFIX/bin`，Windows 为 `%USERPROFILE%\.local\bin`），并区分安装 / 升级 / 已是最新。若本地版本更新则保留而不降级。选项：`--force`、`--preview`、`--musl`、`--skip-github`、`--install-dir <dir>`、`--lang en|zh`，以及同名 `DBXT_*` 环境变量（`--help` 列出全部）。

## 快速上手

1. 运行 `dbxt` —— 读取与 DBX 桌面端相同的存储。
2. 选择连接（`↑` `↓` + `Enter`），或按 `c` 新建。
3. 在表上按 `Enter` 浏览数据；侧栏直接输入字母即过滤表名（`Enter` 打开第一个命中），`d` 切换数据库。
4. `e` 编辑单元格、`i` 插入、`Delete` 删除 —— 每次执行前展示完整 SQL。
5. `F5` 执行编辑器 SQL；`?` 打开完整快捷键帮助（编辑器内用 `F1`，因为 `?` 是字面字符）。

数据库在堡垒机后面时：按 `c`，把 `ssh_tunnel` 设为 `y`，填写 `ssh_host` / `ssh_user` 与登录方式，光标移到保存行按 `Enter`。此后连接链路为 dbxt → 跳板机 → 数据库。

## 持久化与配置

按表偏好（列宽压缩、隐藏列、排序）与记住的列宽（结果区 `<`/`>`）写入 `~/.config/dbxt/tui.json`，以 `库.表` 为键（列宽另带连接与列名，上限 200 条、LRU 淘汰）；`DBXT_CONFIG` 可覆盖路径，`DBXT_NO_PERSIST=1` 可关闭。`DBXT_LANG=en|zh` 选择界面语言（未设置时由 locale 决定），`DBX_DATA_DIR` 指定其他 DBX 存储，`DBXT_INSTALL_DIR` 是安装脚本的目标目录。

SSH 隧道的单测（序列化形状、表单映射、认证/错误分类、主机密钥提示）随 `cargo test` 运行。另有两个端到端测试会驱动真实隧道（dbxt → 本机 `sshd` → MySQL），默认跳过，需 `DBXT_SSH_TEST=1` 开启；它们读取 `DBXT_SSH_TEST_USER` / `_PASSWORD` / `_KEY`、`DBXT_SSH_TEST_MYSQL_PORT`（默认 13306）与 `DBXT_SSH_TEST_MYSQL_USER` / `_PASSWORD`。`tests/secret_store.rs` 也随 `cargo test` 运行：它临时生成一个 `DBX_SECRET_KEY_FILE`，写入加密连接再读回密码（密钥不提交）。

## DBX Secret Store 兼容

dbxt 基于 **DBX v0.6.27** 构建。自 v0.6.27 起，内核会对连接 / 插件 / AI / 隧道等敏感字段强制加密落库（`dbxenc1` envelope，AES-256-GCM），密钥存放在**数据库之外**。dbxt 不做任何密钥管理 —— 密钥解析完全透传内核 —— 因此能打开哪类库取决于密钥提供者是否可达。

| 库状态 | dbxt 行为 |
| --- | --- |
| 明文（旧版，尚未迁移） | 拒绝打开，报 `DATA_MIGRATION_REQUIRED` 并提示：请先在 DBX 桌面端（或 Web）完成「**数据安全升级**向导」。dbxt 不迁移数据，也不绕过这道门。 |
| 密文，密钥可达 | 透明打开；密码与隧道凭据照常解密。 |
| 密文，密钥不可达 | 拒绝打开，报 `SECRET_KEY_UNAVAILABLE` 并提示下方密钥来源。 |

**密钥来源**（内核解析顺序）：

1. `DBX_SECRET_KEY_FILE` —— 密钥文件路径（64 位十六进制、base64url 32 字节，或经 Argon2id 哈希的密码短语）。无桌面 / 容器环境首选。
2. `DBX_SECRET_KEY` —— 直接把密钥材料放进环境变量。
3. 系统钥匙串 —— macOS Keychain、Windows 凭据管理器、Linux Secret Service（由 `os-keyring` feature 编译进内核）。DBX 桌面端把密钥存在这里。
4. `<data-dir>/.dbx/secret.key` —— 内核管理的用户级兜底密钥。

CLI/MCP 进程只**读取**密钥：不创建、不迁移旧凭据。若没有桌面端，请导出密钥（`DBX_SECRET_KEY_FILE`）供 dbxt 解密。

版本对应：基于明文时代内核（v0.6.9 及更早）构建的 dbxt 无法读取桌面端已升级的库 —— 升级 dbxt 与桌面端同步。反之亦然：v0.6.27 内核不会静默读取明文库，请先完成向导。

## 状态与路线图

早期但已可用。已对真实 MySQL 8.4、PostgreSQL 16、Redis 和 MongoDB 端到端实测。

**PostgreSQL** —— SQL 后端全程按 PostgreSQL 方言工作。标识符用双引号（`"schema"."table"`，含保留字）；`bytea`（`0x…` 单元格可回写为 `'\x…'::bytea`）、`uuid`、`jsonb`、数组（`ARRAY[…]`）与枚举均完整显示，复制/导出为合法 SQL；插入模板跳过 `serial`/identity 列，让序列保持权威；`Ctrl-P` 走普通 `EXPLAIN`（绝不用 `EXPLAIN ANALYZE`），写语句只生成计划、不实际执行。表结构与 DDL 读取 `pg_catalog`（`information_schema` 兜底），DDL 会解析关系的可见 schema（`CREATE TABLE "public"."accounts"`，含索引、约束与注释）。浏览全程感知 schema：`d` 列出当前库的 schema（schema 在前、库在后），侧栏显示 `inv.items` 式全限定名，表格数据、表结构、DDL、单元格编辑、插入、删除、过滤、排序、CSV 导入/导出与 INSERT 导出都会带上所选 schema —— `public.orders` 与 `inv.orders` 不会串。列显隐、排序与 `COUNT(*)` 缓存均按 `database.schema.table` 分键。

## 已知问题

诚实列出**尚未实现**的部分，避免发版后才被发现。

- **表尺寸元数据仅支持 MySQL / PostgreSQL。** 在库行上按 `s`，SQLite、DuckDB 等引擎会提示 *该引擎不支持尺寸查询* —— 侧栏尺寸列在这些引擎上保持为空。
- **全局搜索（`Alt-G`）仅支持 MySQL / PostgreSQL** —— 它扫描每张表的 `char` / `varchar` / `text` 列，未接入其他引擎。
- **不支持 `.xlsx` 导入，也不支持 XLSX 导出** —— 有意不做；请使用 CSV。
- **搜索是页内搜索** —— `/` 只搜可见行，不搜整个结果集；跨页结果搜索尚未实现。
- **大结果导出只警告不阻断** —— 结果集超过 10,000 行时，`Ctrl-Y` 会先提示。
- **只读判定保守失败** —— 未知动词一律算写语句，因此极少数“看着像读”的语句会被按设计拒绝。
- **Redis / MongoDB 不在范围内** —— 不参与 `Alt-T` 搬运向导，也不参与 `Alt-D` / `Alt-K` 的结构与数据比对。
- **预编译包只在本机验证过 Linux x86_64** —— 其余六个平台在 CI 构建但未实测。
- **没有独立的 Android/Termux 产物** —— 静态 aarch64 构建通常可用，否则从源码构建。
- 连接树**每会话只读一次**桌面端分组布局，因此在 DBX 桌面端重新分组后，下次打开 dbxt 才会生效。

Apache-2.0，与 DBX 相同。dbxt 是基于 [t8y2](https://github.com/t8y2) 的 [DBX](https://github.com/t8y2/dbx) 内核构建的独立客户端；不是 fork，与 DBX 项目无隶属或背书关系。
